# 棋友 Go｜圍棋學習與 AI 對弈

此資料夾為獨立的 GitHub Pages 圍棋學習網站，直接以瀏覽器開啟 `index.html` 即可使用，不需安裝套件或架設後端。

## 功能
- 9 路、13 路、19 路棋盤
- 入門陪練、初級挑戰、進階挑戰三種電腦程度
- 落子前可預覽候選位置，確認後才正式落子
- 落子後提供局部棋形回饋
- 點選棋譜逐手回看當時棋盤與建議
- 落子前推薦位置與局部棋形提示
- 落子後提供棋形回饋
- 提子、打吃、自殺著與簡化劫規則判斷
- 悔棋、停一手、棋譜與圍棋基本觀念

## 開啟網站
部署完成後：`https://jimmybigsuccess.github.io/knight_dragon_web/go-study/`

## 技術說明
使用原生 HTML、CSS、JavaScript 與 Canvas 繪製棋盤，無外部套件依賴。電腦採用本機啟發式策略評分，定位為入門教學陪練，不等同 KataGo 等專業圍棋引擎；終局目數為簡化估算。
