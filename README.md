# 騎士與龍 v1.8｜遊玩說明

這是由玩家製作、以《騎士與龍》為靈感的**非官方網頁遊戲原型**，不是原版程式或官方發行作品。介面以直式手機操作為主要設計方向。

## 進入遊戲

開啟網站後選擇「開始冒險」，於主城可前往冒險地圖、裝備、商店、任務、騎士資料、圖鑑與存檔管理。新遊戲從 **Lv.1、訓練木劍、25 G、補給 ×3** 開始。

## 四格武器與盾牌編成（v1.8）

- **四個裝備欄位均可自由裝配武器或盾牌**，不限固定武器欄或固定盾牌欄。從主城進入「裝備」，在持有的物品下點選「1～4 號位」即可放入指定位置。
- **每一件裝備提供兩種技能**，四張戰鬥技能卡分別對應四個裝備欄。點擊技能卡即可發動該欄當前技能；使用後切換成該件裝備的另一種技能。下方「下一招」顯示下一次將輪到的技能。
- 技能右上角數字乘以 10 即為 AP 消耗。初期木劍有快速斬擊及針對怪物的攻擊；木製小盾則有低消耗「架盾」與較高消耗「盾擊」。
- **沒有獨立的永久防禦鍵與補給鍵。** 只有裝備有「架盾／奇蹟護盾」的盾牌才能進行防禦；「戰地補給」僅由補給盾提供，並且仍須消耗背包中的一份補給。
- 精準格擋須在敵方攻擊前約 0.65 秒內觸發盾牌防禦技能。成功後防住該次攻擊並恢復 AP；過早施放只能短時間減傷。
- 每種武器技能有不同傷害、AP 消耗和 PP 累積效果。依照怪物弱點調配四格編成。當 PP 滿時，敵人會暈眩；每個區域共有六波戰鬥，第六波是 BOSS。
- **新玩家起步裝備**為訓練木劍與木製小盾（可配置於多格）；既有玩家保留原本武器，並自動獲得一面基礎盾牌，不清除通關紀錄。

## 新手拓荒與成長

首勝、三勝、五勝、首次擊敗洞窟 BOSS 等里程碑有固定報酬；前往主城的「任務／拓荒手札」手動領取。累積 3 場勝利可領長槍，擊敗洞窟 BOSS 可領聖劍。一般怪物會提供鍛造礦石，各區 BOSS 提供區域素材，可在裝備頁強化武器。武器最高 +9，後期強化需要更多素材。

## 圖鑑與稀有度（v1.8）

主城的「圖鑑」會顯示已持有的武器、**武器固定稀有度**、探索札記、BOSS 收藏與 3 個區域合計 **18 種怪物**的討伐次數。未曾討伐的怪物顯示為未知。首次突破第二階段 BOSS 會保留紀錄。稀有度暫時是分類資訊，**不額外增加攻擊倍率**，避免破壞拓荒平衡。

## v1.8 專屬 BOSS 招式與探索選擇

- 水晶洞窟 BOSS 覺醒後可能使用「晶簇崩落」，被命中會額外扣除 22 AP。
- 綠蔭森林 BOSS 會使用「荊棘纏繞」，造成額外生命傷害。
- 熔岩山脈 BOSS 會使用「熔岩噴發」，為準備時間較久、傷害較高的招式。
- 冒險地圖的探索事件改為二選一：**補給優先**（較多食物），或 **金幣優先**（額外金幣）。每區仍只能領一次；原有存檔的已探索事件不會再次給獎。
- 自累積第 6 場勝利後，如果還有未取得的武器，勝利時將有機率發現新武器；**連續 5 次符合資格卻沒有發現時保證獲得一把**。已擁有全部武器時不再觸發。

## v1.8 旅途奇遇與新裝備演出

- 每個區域的第 2、4 波**首次勝利後**，結算畫面會遇到旅途事件，可在兩份獎勵間選一份（總共 6 個事件）。有礦石、金幣、補給或 HP 回復等選項。每個事件只能領取一次，回來重複刷關不會重領。
- **必須先選擇事件獎勵才能按「下一波」**。若先回主城，該事件未領取，重新挑戰該波後仍可選擇。
- 第六場勝利後有機會隨機取得還沒擁有的武器，且有保底機制。**新武器掉落時**結算畫面會顯示放大的武器圖示、武器名稱、稀有度與基礎攻擊力。領取後可到主城「裝備」配置使用。
- 冒險圖鑑新增旅途奇遇紀錄，可查看六個事件的完成情況。

## 主城功能

- **冒險**：選擇已解鎖區域，也能觸發每區一次的探索事件。
- **裝備**：四格武器／盾牌編成、鍛造與素材清單。
- **商店**：購買補給、隨機裝備寶箱、旅店恢復。
- **任務**：領取固定拓荒獎勵與日常式挑戰（目前為一次性目標）。
- **騎士資料**：檢視等級、勝場、奇蹟格擋與收藏數量。
- **圖鑑**：查看已登錄怪物、武器與探索收藏。
- **存檔管理**：備份、匯入進度，或刪除紀錄重新開始。

## 存檔、重新開始與手機使用

遊戲進度自動儲存在目前瀏覽器（localStorage）；**不同裝置不會自動同步**。在主城打開「存檔管理」，使用「產生備份文字」並妥善複製保存；在另一台裝置貼上、按「匯入」即可轉移。

要完全重新拓荒，先備份進度，再點「刪除遊戲紀錄」，手動輸入 **重新開始** 確認。這只會刪除當前瀏覽器的遊戲存檔，不會刪除已備份文字。

iPhone 可在 Safari 開啟 GitHub Pages 網址並透過分享選單「加入主畫面」；Android Chrome 也可加入主畫面。遊戲可使用 GitHub Pages 發布，不需要啟動 Python 後端。

**網站：** https://jimmybigsuccess.github.io/knight_dragon_web/

**注意：** 若更新後仍顯示舊版，可重新整理、關閉再開啟已安裝的捷徑，必要時清除此網站的離線快取；清除網站資料可能連同存檔一起刪除，請先備份。

## v1.8 手機單頁介面與繁體中文

- 戰鬥中的怪物、武器、技能卡、盾牌等主要按鈕會一起呈現在手機畫面，不必上下捲動才能按到技能或防禦。
- 主城八種主要功能改為 4 × 2 緊湊式按鈕排列；成長目標、里程碑仍可在「任務」或「騎士資料」查看。
- 圖鑑、任務、裝備、說明與存檔管理資料量較多，**僅內容面板可以捲動**，右下方固定「返回主城」按鈕。
- 戰鬥中的「下一張、連擊、勝利、戰敗、弱點」及所有技能名稱已統一使用繁體中文；能力縮寫 HP／AP／PP、BOSS 與等級記號仍保留慣用表達。
- 直式手機體驗最佳。螢幕特別矮或橫向顯示時，長說明仍可能需要在面板內捲動。
- 更新 GitHub Pages 後若顯示舊版，請重新整理頁面或關閉網站後重開，以更新離線快取。
