# 騎士與龍 — 非官方網頁原型 v0.5（手機支援版）

## 手機可玩

遊戲支援 iPhone Safari、Android Chrome 的觸控操作與直式螢幕，包含開始畫面、主城功能選單、冒險、戰鬥、裝備、商店、任務、結算及本機自動存檔。操作直接點擊技能卡／武器／防禦。畫面適配窄螢幕、瀏海及底部安全區域；切換 App 時暫停敵人攻擊計時。

### 方法 A：部署成 HTTPS 網站（推薦）

將 `index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` 放在同一個公開靜態網站目錄（例如 GitHub Pages、Netlify、Cloudflare Pages）。這些檔案本身即可遊玩，不需要 Python 後端。取得 HTTPS 網址後在手機 Safari 或 Chrome 開啟。

- iPhone：Safari → 分享 → 加入主畫面。
- Android：Chrome → 選單 → 安裝應用程式／加到主畫面。
- 首次透過 HTTPS 載入後，支援 Service Worker 的瀏覽器可在離線狀況開啟已快取的遊戲。
- 注意：本專案**尚未代你部署到網路上**，因此下載的 HTML 檔案不是一個可直接從任何手機使用的公開網址。

### 方法 B：電腦＋手機在同一個 Wi-Fi

1. 電腦解壓 ZIP；在專案資料夾執行 `python server.py`。
2. 找出電腦的區域網路 IPv4 位址（例如 `192.168.1.23`）。
3. 手機連同一個 Wi-Fi，用瀏覽器開啟 `http://192.168.1.23:8000`（替換為實際 IP）。
4. 如無法連線，檢查電腦防火牆是否允許 TCP 8000 與 Wi-Fi 用戶端隔離設定。

本地區網 HTTP 可玩遊戲，但要可靠使用「加入主畫面」及離線快取，建議正式部署至 HTTPS 網站。

### 方法 C：直接開啟 index.html

部分桌面瀏覽器可直接開啟；手機對本機檔案與 PWA 的支援差異很大，建議方法 A。

## 遊戲內容

開始畫面 → 主城 → 冒險地圖 → 戰鬥 → 勝負結算 → 下一波／主城；具備 AP、PP、技能 NEXT、武器切換、連擊、敵人倒數、精準防禦、鍛造、任務、商店。

## 存檔與版權

存檔寫入**目前瀏覽器、目前網站來源**的 localStorage，不會自動在電腦、手機或不同網址間同步；清除網站資料可能遺失進度。這是非官方致敬原型，未使用原作擷取的圖片與聲音；首頁、主城與未考證內容為暫擬設計。
