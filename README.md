# 騎士與龍 v1.4｜遊玩說明

這是由玩家製作、以《騎士とドラゴン》為靈感的**非官方網頁遊戲原型**，不是原版程式或官方發行作品。介面以直式手機操作為主要設計方向。

## 進入遊戲

開啟網站後選擇「開始冒險」，於主城可前往冒險地圖、裝備、商店、任務、騎士資料、圖鑑與存檔管理。新遊戲從 **Lv.1、訓練木劍、25 G、補給 ×3** 開始。

## 戰鬥操作

- 點擊畫面下方的技能卡攻擊；卡片右上數字乘以 10 即為 AP 消耗。用掉的牌會從 NEXT 補牌。
- 點擊四個武器欄位切換裝備，每把武器有不同技能與被動效果。利用屬性弱點獲得額外傷害。
- 敵方行動倒數至最後約 **0.65 秒** 時按「防禦」可發動奇蹟格擋、阻止該次傷害並回復 AP。過早防禦僅能短暫減傷；盾牌有冷卻時間。
- 連續施放不同屬性的技能可觸發 CHAIN BURST。累積 PP 至 100 可使怪物短暫暈眩。
- 「吃肉」消耗一份補給，恢復 AP 與少量 HP。手機切至背景時戰鬥會自動暫停。
- 每區域共有六波怪物，第六波為 BOSS。**BOSS HP 降至一半且尚未倒下時，將進入第二階段**，攻擊會加快、變強，戰鬥畫面會顯示階段提示。

## 新手拓荒與成長

首勝、三勝、五勝、首次擊敗洞窟 BOSS 等里程碑有固定報酬；前往主城的「任務／拓荒手札」手動領取。累積 3 場勝利可領長槍，擊敗洞窟 BOSS 可領聖劍。一般怪物會提供鍛造礦石，各區 BOSS 提供區域素材，可在裝備頁強化武器。武器最高 +9，後期強化需要更多素材。

## 圖鑑與稀有度（v1.4）

主城的「圖鑑」會顯示已持有的武器、**武器固定稀有度**、探索札記、BOSS 收藏與 3 個區域合計 **18 種怪物**的討伐次數。未曾討伐的怪物顯示為未知。首次突破第二階段 BOSS 會保留紀錄。稀有度暫時是分類資訊，**不額外增加攻擊倍率**，避免破壞拓荒平衡。

## 主城功能

- **冒險**：選擇已解鎖區域，也能觸發每區一次的探索事件。
- **裝備**：四格武器配置、鍛造與素材清單。
- **商店**：購買補給、隨機武器寶箱、旅店恢復。
- **任務**：領取固定拓荒獎勵與日常式挑戰（目前為一次性目標）。
- **騎士資料**：檢視等級、勝場、奇蹟格擋與收藏數量。
- **圖鑑**：查看已登錄怪物、武器與探索收藏。
- **存檔管理**：備份、匯入進度，或刪除紀錄重新開始。

## 存檔、重新開始與手機使用

遊戲進度自動儲存在目前瀏覽器（localStorage）；**不同裝置不會自動同步**。在主城打開「存檔管理」，使用「產生備份文字」並妥善複製保存；在另一台裝置貼上、按「匯入」即可轉移。

要完全重新拓荒，先備份進度，再點「刪除遊戲紀錄」，手動輸入 **重新開始** 確認。這只會刪除當前瀏覽器的遊戲存檔，不會刪除已備份文字。

iPhone 可在 Safari 開啟 GitHub Pages 網址並透過分享選單「加入主畫面」；Android Chrome 也可加入主畫面。遊戲可使用 GitHub Pages 發布，不需要啟動 Python 後端。
