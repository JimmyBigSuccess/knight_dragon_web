# ⚔️ 騎士與龍｜遊玩說明（v0.7）

這是一款向日本《騎士とドラゴン》致敬的**非官方網頁遊戲原型**。請使用手機直式畫面遊玩；也支援電腦瀏覽器。這並非原版遊戲的完整復刻，部分地圖、數值與美術為自行設計。

## 一、如何開始遊戲

1. 開啟 `index.html`（電腦）或手機遊戲網址（須先部署到 HTTPS 網站）。
2. 在標題畫面點選「**開始冒險**」，進入主城。
3. 點選「**冒險**」，從已開放的地區選擇關卡。
4. 每個區域有六波敵人，第六波是 **BOSS**。戰勝後可選擇下一波，或返回主城。
5. 遊戲會在目前瀏覽器**自動存檔**。

## 二、新手拓荒：前期成長路線

新存檔從 **聖劍、25 G、3 份補給** 起步；四個武器欄一開始可重複裝備聖劍，不用等蒐集到四把才能出門。主城會顯示「🌱 拓荒手札」的下一個目標，任務頁可查看全部目標並**手動領取**獎勵。

| 里程碑 | 達成方式 | 固定獎勵 |
| --- | --- | --- |
| 冒險的第一步 | 贏得第 1 場 | 40 G |
| 新手的第一把長槍 | 累積第 3 場勝利 | 長槍、30 G |
| 站穩腳步 | 累積第 5 場勝利 | 補給 ×2、30 G |
| 洞窟征服者 | 首次擊敗水晶洞窟 BOSS | 魔杖、120 G、補給 ×2 |
| 獨當一面的騎士 | 累積 10 場勝利 | 戰斧、100 G |
| 盾牌的奧義 | 奇蹟格擋 3 次 | 60 G |
| 森林開拓者 | 首次擊敗綠蔭森林 BOSS | 火焰劍、160 G |

建議前期先完成 3 場勝利取得長槍，返回主城配置裝備；資源不足時領取拓荒獎勵、購買補給或重玩已開放的區域。普通關卡後期仍有機會隨機掉落武器，但**拓荒的重要武器不需要靠運氣取得**。

> 舊版 v0.6 存檔會繼續沿用原本的武器、金幣及戰績，不會強制重置為新手狀態；如果已達到新的拓荒目標，可以在任務頁領取對應獎勵。建議更新前先到存檔管理備份。

## 四、戰鬥怎麼玩？

- **HP（生命值）**：受到敵人攻擊會減少，歸零即戰敗；可使用補給或到旅店恢復。
- **AP（行動點數）**：施放技能時消耗；技能卡上的 `1` 表示消耗 10 AP，`5` 表示消耗 50 AP。AP 不足時技能卡會變暗。
- **技能卡**：點按畫面下方四張技能卡之一進行攻擊；使用後會由 `NEXT` 佇列補入新卡。
- **四個武器欄**：初期可使用重複聖劍，隨著拓荒手札解鎖新武器；點按武器欄切換目前使用的武器與對應技能。不同武器具有不同屬性及攻擊力。
- **WEAK（弱點）**：使用克制敵人弱點的屬性技能，造成額外傷害。
- **HIT／連技**：連續攻擊提高 HIT 數；在一定時間內使用不同屬性技能，可觸發 `CHAIN BURST`。
- **PP／暈眩**：攻擊技能累積 PP，達到一定程度能使敵人暫時失去行動能力。
- **敵人攻擊倒數**：畫面右上方會顯示敵人的攻擊剩餘秒數與進度條。
- **🛡️ 防禦**：敵人快攻擊、畫面提示「防禦！」時按下盾牌可發動「奇蹟格擋」，完全擋下攻擊並回復 AP；過早按則僅提供短暫減傷。
- **🍖 吃肉補給**：每次使用一份補給，恢復 35 AP 與 15 HP。補給可在商店購買，也能透過部分戰鬥獎勵取得。
- **Ⅱ 暫停**：點右上角按鈕暫停，點 ▶ 恢復。手機切換到其他 App 時會暫停計時，回來後再手動恢復。

**建議技巧：** 留意倒數，先用低 AP 技能累積 PP，敵人快出招時準備防禦；打不過時返回主城鍛造或補給。

## 五、武器、金幣與通關

- 戰鬥勝利會得到金幣，拓荒里程碑可固定取得武器；第 6 場勝利後才會開始有機會隨機掉落尚未擁有的武器。
- 裝備頁能將已獲得的武器放入四個欄位。鍛造消耗金幣，單把武器最高強化至 +9。
- 商店中的補給 20 G、隨機武器寶箱 80 G、旅店休息 30 G；鍛造為 65 G。
- 區域共有六波敵人，通過 BOSS 才會開放下一地區。
- 戰敗後可重新挑戰；也可以返回主城整備。

## 六、手機遊玩與加入主畫面

**方法 A：手機直接連網站（推薦）**

你已經使用 GitHub Pages 測試，可將新版專案根目錄內的 `index.html`、`sw.js`、`manifest.webmanifest` 和圖示一起更新到目前 Pages 發布的資料夾；網站必須是 HTTPS。GitHub Pages 不需要執行 `server.py`。本專案附有 `manifest.webmanifest`、`sw.js` 與圖示，適合在支援的瀏覽器加入主畫面。

- **iPhone**：Safari 開啟遊戲網址 → 分享 → 加入主畫面。
- **Android**：Chrome 開啟遊戲網址 → 右上角選單 → 安裝應用程式或新增至主畫面。
- 第一次成功載入後，在支援 Service Worker 的 HTTPS 網站環境中可嘗試離線開啟。正式部署後請先連網開啟一次。

**方法 B：家中 Wi-Fi 試玩**

1. 電腦解壓 ZIP，安裝 Python 3。
2. 在專案資料夾執行 `python server.py`。
3. 手機與電腦連上同一個 Wi-Fi，手機輸入 `http://電腦的區域網路IP:8000`（例如 `http://192.168.1.23:8000`）。
4. 若無法連線，確認電腦防火牆與 Wi-Fi 裝置隔離設定。

普通區域網 HTTP 不保證支援安裝或離線快取；直接在手機開啟本機 `index.html` 也可能受到瀏覽器限制。

## 七、如何把電腦進度搬到手機？

1. 在舊裝置進入主城 → **存檔管理** → **產生備份文字**。
2. 點「複製備份文字」，將整段文字存到備忘錄或傳給新裝置。
3. 在新裝置的同一遊戲版本進入 **存檔管理**，貼上文字後按「匯入並覆蓋目前存檔」。
4. 匯入後會回到主城，確認角色等級與金幣是否正確。

⚠️ 匯入會覆蓋當前裝置存檔。存檔僅儲存在個別瀏覽器的 localStorage，**不會跨裝置自動同步**；清除瀏覽器網站資料也可能導致資料遺失，建議定期備份。

## 八、常見問題

**Q：為什麼技能無法按？** 可能是 AP 不夠、戰鬥暫停或當前不在戰鬥階段。請檢查 AP 與右上角的暫停按鈕。

**Q：畫面卡住，怪物不攻擊？** 可能是遊戲自動暫停，點擊 ▶ 即可繼續。

**Q：手機按下檔案連結卻不能直接玩？** ZIP／HTML 下載不是公開網站網址。建議先部署 HTTPS 網站或使用同 Wi-Fi 的 Python 伺服器。

**Q：GitHub Pages 更新後還是舊畫面？** 重新整理頁面；若已加到手機主畫面，可關閉並重新打開。離線快取已更新版本號，裝置需要連網取得新版本。請確定 `sw.js` 也一起上傳。

**Q：存檔不見？** 檢查是不是換了手機、瀏覽器、網址或無痕模式；不同網站來源的存檔彼此獨立。
