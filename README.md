# 騎士與龍 v6.1｜8-bit 改版與遊玩說明

《騎士與龍》是一款受早期手機遊戲啟發的**非官方網頁遊戲原型**。可在手機瀏覽器直式遊玩，也可部署至 GitHub Pages。

## 開始冒險

開啟遊戲，選擇「開始冒險」即可進入主城。從主城選擇「裝備」安排四格裝備，再選擇「冒險」進入關卡。

初次遊玩時，你擁有：
- Lv.1 騎士、25 G、3 份補給。
- **訓練木劍** 1 把與**木製小盾** 1 面。
- 裝備欄預設為木劍、木盾及**兩個空欄**。空欄不會提供技能。

## 裝備編成

在主城打開「裝備」：
1. 點選**上方四格裝備欄**中想調整的格子。
2. 點選**下方背包**中的武器或盾牌，即可裝到該格。
3. 可用「全部／武器／盾牌」篩選物品；也能選擇「卸下所選裝備」，將該格留空。
4. **同一件裝備只能放在一個格子**。已裝備在其他欄的物品會呈現不可選狀態。至少需留一件裝備才能出發。

**編成僅能在關卡外進行**。開始戰鬥後直到返回主城為止，裝備無法更動；戰鬥畫面沒有裝備編成按鈕。裝備頁的「鍛造與素材」可展開查看強化需求。

## 戰鬥與 AP

- 每個裝備欄對應一張技能卡；每件武器或盾牌各有**兩個輪替技能**。使用後，該欄切換為另一技能。
- 技能卡的消耗數字每 1 點代表 **10 AP**。例如卡片顯示 2，施放時消耗 20 AP。
- **AP 在戰鬥進行時自動恢復：每秒 8 AP，最多 100 AP。** 耗盡時可先等待恢復，不必依賴盾牌技能。暫停、結算或離開戰鬥時不會繼續回復。
- 防禦與補給**不是固定按鈕**：只有配置具備對應技能的盾牌，輪到該技能時才能施放。
- 使用「架盾」等防禦技能，在敵方攻擊前約 0.65 秒出手可達成奇蹟格擋；太早舉盾則只有短時間減傷。
- HP 是生命值；PP 累積滿時可使敵人暈眩。不同敵人具有弱點與攻擊預告，部分 BOSS 在半血以下會進入第二階段。

## 探索、獎勵與成長

每區域包含六波怪物，第六波為 BOSS。完成首次勝利、累積勝場與 BOSS 討伐等拓荒目標，可前往主城「任務」領取固定獎勵。後續可獲得長槍、聖劍、魔杖等裝備，並收集鍛造素材強化武器和盾牌。

冒險地圖與指定波次也會出現一次性探索事件；通關結算可選擇獎勵。主城「圖鑑」可查看已發現的裝備、怪物與收藏品。

## 主城選單

- **冒險**：進入已解鎖的區域與探索事件。
- **裝備**：配置武器和盾牌、鍛造。
- **商店**：購買補給、裝備寶箱及旅店休息。
- **任務**：領取拓荒與討伐獎勵。
- **騎士資料、圖鑑**：查看能力、戰績、怪物和收藏紀錄。
- **存檔管理**：備份、匯入或清除遊戲紀錄。

## 存檔與重新開始

進度自動儲存在目前瀏覽器的 localStorage，不同裝置不會自動同步。可在「存檔管理」中產生備份文字，複製到其他裝置後匯入。

若想重新拓荒，現在可直接在「存檔管理」按下刪除存檔立即重置，方便測試。此操作會清除目前瀏覽器內的遊戲進度，但不影響已自行留存的備份。

**舊版存檔相容說明：** 更新 v2.3 時，不會清除既有武器、金幣或通關進度。原本重複裝備同一件物品的欄位，會保留首次出現的一格，其餘自動留空。

## 手機與網站

建議使用手機**直式**瀏覽，主要操作集中在單一畫面；背包與圖鑑可在內容區域內捲動。iPhone Safari、Android Chrome 可將 GitHub Pages 網站加入主畫面。

測試網站：https://jimmybigsuccess.github.io/knight_dragon_web/

更新網站檔案後如仍看到舊版，可重新整理網頁或重新啟動桌面捷徑。清除瀏覽器網站資料有可能同時刪除存檔，因此操作前務必備份。


## v2.3 戰鬥介面與 AP 條

- AP 在戰鬥中每秒恢復 8 點，但 **AP 條本身寬度固定**，只會改變已填充的進度。刻度線固定，不會跟著 AP 增加而伸長。
- 戰鬥畫面採用金屬框、暖金邊線、深色技能底板和四格技能／下一招排列，參考早期《騎士與龍》UI 風格重新繪製；未直接使用原版美術素材。
- 只有 AP 達到技能所需門檻時才重繪技能卡狀態，以免持續恢復 AP 時產生閃動。

## v2.3 戰鬥畫面調整

介面參考玩家提供的真正原版戰鬥截圖與 [《騎士與龍》UI 典藏](https://www.qbnews.tw/game-ui-ui_35/)。調整回合進度條、連擊顯示、敵人生命值、金屬框 HP/AP、裝備欄與技能卡，以及逐格對應的下一招預覽。原版美術與角色圖片並未直接複製。戰鬥規則、AP 自動恢復、裝備限制及既有存檔保持不變。

## v2.3 操作與流暢度修正

- AP 填充層改為固定寬度，使用縮放呈現剩餘比例，底層分段刻度不變形。
- AP 恢復跨過技能門檻時，只切換該技能按鈕是否可用，不再整批重建四張卡片，避免觸控中斷與畫面閃動。
- 技能文字可以換行；狹窄螢幕仍以四格對齊呈現。按下技能會有更清楚的回饋，鍵盤操作新增可見焦點。
- 其餘武器／盾牌雙技能、AP 每秒恢復 8 點、裝備規則與原存檔皆維持不變。

此版屬於穩定性與版面優化，並非追加新關卡；戰鬥美術仍為重新製作的替代素材。


## v2.4 戰鬥演出優化

本次僅更新戰鬥畫面，**沒有新增關卡，也沒有修改技能傷害、AP 恢復速度、四格裝備或存檔規則**。

- **突刺技能：** 槍系／旋風突刺使用直線突進與殘影。
- **重擊技能：** 高耗 AP 重擊使用地面震波與撞擊效果。
- **魔法技能：** 魔法彈與魔力爆發使用由中心向外擴散的光環。
- **連續斬擊：** 以多道斬擊弧線呈現連擊。
- **敵人預警：** 敵方攻擊前 0.9 秒，戰鬥場景出現半透明色彩警示；不同招式的顏色略有差異，避免只靠小字閱讀倒數。
- **BOSS 第二階段：** 血量降至一半後，敵人資訊框追加醒目的高亮邊線。
- **減少動態：** 如果手機／電腦開啟「減少動態效果」，部分光效改為較低強度。

這些動畫為重新繪製的原創效果，不是原版圖片或特效素材。保留玩家存檔，更新 GitHub Pages 前仍建議先在遊戲中備份。

## v4.7｜進入關卡後手動開始

從主城選擇區域後，會先顯示「開始戰鬥」按鈕。尚未點擊之前，敵人不會攻擊、倒數不會前進、AP 不會自動恢復，也無法施放技能。按下後才正式開始戰鬥。戰敗後點選重新挑戰，也會重新等待按下開始。已開打的同一關後續波次則維持原本流程。


## v4.7｜戰鬥操作與暫停

- 剛進入關卡仍需按「開始戰鬥」，敵人倒數與 AP 才會開始。
- 戰鬥中點擊右上角暫停，可選擇「繼續戰鬥」或「返回主城」。
- 返回主城前會要求確認；放棄當前波次不會保留該波敵人的傷害進度。
- 尚未獲勝時隱藏「下一波」按鈕，減少手機畫面佔用。
- 切換到其他 App 時自動暫停，返回後需手動繼續。
- 所有裝備、傷害與存檔格式維持原設定。


## v4.7｜每波戰鬥結算與下一波預告

- 勝利結算清楚顯示金幣、連擊、剩餘 HP 與戰利素材。
- 顯示下一波的魔物名稱、關卡與弱點，BOSS 會另外標示。
- 按下「前往下一波」後，先進入準備狀態，不會立即開戰。
